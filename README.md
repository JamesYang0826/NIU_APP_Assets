# 宜大學生 app 完整詳細更新日誌

## 1.0.9 更新內容
- _新增_：主畫面功能：校園信箱 ( NIU Mail )
- _修復_：系統：部分使用者，未成功登錄「首次登入日期」之錯誤
- _更新_：系統：app 方形 icon 圓角化
- _更新_：系統：支援 Android 15+ 16KB 記憶體分頁裝置

## 1.0.8 重量級更新內容
- _更新_：系統：大幅增加 登入/登出 速度 ( 改為使用sso整合登入系統，但會要求180天變更密碼 )
- _修復_：系統：帳密正確，仍顯示帳密錯誤問題 ( 密碼到期後，無法透過帳密登入zuvio導致 )
- _修復_：M園區：部分區塊隱藏錯誤的問題
- _增加_：M園區：YouTube 資源可自動開啟 YouTube App
- _增加_：M園區：資源下載進度條，完成後跳出「如何開啟」選擇介面
- _更新_：系統：改善網頁無法操作問題 ( 降低對 WebView Provider Beta 的依賴 )
- _更新_：系統：targetSDK 36，安卓16適配


## 1.0.7 更新內容
- _修復_：我的課表：無法顯示課表問題 ( 暗黑模式可能有閃爍，還請見諒 )
- _更新_：活動報名：活動備註欄限制高度 ( 曾經有備註太長超出螢幕 )

## 1.0.6 更新內容
- _修復_：Zuvio：題目無法送出 Bug
- _修復_：成績查詢：點擊太快導致閃退 Bug
- _新增_：系統：網頁直接崁入畫面 ( 問卷, zuvio... )，右上角新增「說明」按鈕

## 1.0.5 更新內容
- _修復_：M園區：直接按返回鍵可能導致閃退之Bug
- _修復_：Zuvio：地圖選擇，拒絕定位權限亦可使用
- _增加_：活動報名：活動列表新增「詳細」按鈕
- _增加_：系統：添加 Firebase Crashlytics，大部分 Crash Log 都能在此捕捉於後台，讓開發人員能以最快速度修復
- _增加_：系統：添加 Crash 偵測，可於意外發生時進行回報 ( 會複製 Log ) ( 上述功能未捕捉成功之Log亦可直接回報 )
